# Retained non-psychedelic study examples, v1

Ten distinct NCT identifiers selected in the verified `review/studies/non-psychedelic-2026-10-13/` packet outside this repository. Publication was explicitly authorized by Keith on 2026-10-13. These are version-controlled examples, not a database import or a live API cache.

- Each `NCT*.json` preserves exact bytes from the packet's full-module official ClinicalTrials.gov capture. This capture includes date types and comparator arms omitted by the narrower live client's field selection. The existing trial schema and normalizer render its core facts without changing the live client.
- `catalog.json` retains exact query URLs, retrieval/processing times and SHA-256 hashes; concise original summaries, source discrepancies and scientific-review status remain separate from structured facts. `PENDING` is not converted to human approval. The ordered collection is not an efficacy ranking.
- `publications.json` contains the exact Europe PMC bibliographic response. Only citation metadata, public links and original notes are displayed; no publication full text is included. PMID linkage is retained in registry references for nine trials and in the linked original aticaprant paper for NCT03559192.
- Attribution: ClinicalTrials.gov / U.S. National Library of Medicine (SRC-CTG/v1) and Europe PMC (SRC-EPMC metadata). Existing source policy plus the explicitly authorized public examples scope applies. No new live source integration is enabled. Keep retained evidence with this version for provenance; replace through a reviewed versioned update, never silently refresh dates or facts.
- Loader validation checks source policy at retrieval, exact bytes, identifiers, publication linkage and uniqueness. Builds generate exactly ten stable `/trials/examples/NCT…` routes; there are no writes or append operations.

Missing dates, unspecified date types and source-specific enrollment denominators remain visible. Effect sizes remain unknown/not evaluated. These study pages now link to separate MODEL_INFERENCE programme associations accepted for inclusion in mapping dataset 1.2.0; the original three programme mappings are preserved. The scientific synthesis notes remain PENDING and are not promoted by that inclusion decision. Companion NCT metadata files describe the original full-module responses for mapping validation; they do not replace or refresh the response bytes.
