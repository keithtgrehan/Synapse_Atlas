# Noto Sans PDF fonts

`NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` are unmodified Noto Sans TTF files from the official [Noto Fonts repository](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).

They are embedded by the client-side research-brief PDF renderer so saved evidence is not silently reduced to an ASCII-only font. The accompanying `NotoSans-OFL.txt` is the SIL Open Font License 1.1.
